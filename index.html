01開発したプロダクト

個人開発2026.10–本番公開中

shirube 道標

なりたい職業から、取る授業とその理由、卒業までの時間割を組む Web アプリ

0.52 → 0.72作り直したときの結果の一致度（Jaccard）。揺れを小さくし、費用は 1 件 0.83 円のまま（改善前後を交互に流して比較、p < 0.001）

職業名を入れると、LLM が必要なスキルを読み取り、シラバスを埋め込み検索して候補を集め、LLM がリランクして理由つきで授業を選び、学期ごとの時間割に並べます。改善を始める前に精度・非決定性（揺れ）・費用を測る評価の仕組みを作り、変更を採るかどうかはそれで決めました。

  • Next.js
  • FastAPI
  • PostgreSQL + pgvector
  • OpenAI API
  • AWS EC2
  • Docker Compose
  • GitHub Actions

となり

手元を見て、詰まったときだけ声をかける、答えを言わない AI 家庭教師

紙に書いている手元をスマホで見て、手が止まったときだけ、答えではなく次の一歩を声で示します。自分は API サーバ（状態の管理・ヒントの生成・答え漏れの検査）、手元の静止の判定、デプロイを担当しました。
