shirube 道標

A web app that starts from the career you want and plans which courses to take, why, and your timetable through graduation

Enter a job title: an LLM infers the skills it requires, embedding search over the syllabi gathers candidate courses, an LLM re-reads the candidates and picks courses with reasons, and the app lays them out in a semester-by-semester timetable. Before starting any improvements, I built an evaluation system that measures precision, run-to-run variance, and cost, and used it to decide whether to adopt each change.

  • PostgreSQL + pgvector
  • OpenAI API

tonari

An AI tutor that watches your work, speaks up only when you're stuck, and never gives away the answer

A smartphone watches you write on paper, and only when your hand stops does it voice the next step, not the answer. I handled the API server (state management, hint generation, answer-leak checks), detecting when the writing hand goes still, and deployment.
